# 7. Apache-2.0 and TypeScript

Date: 2026-10-24. Status: accepted.

## Decision

- License: Apache-2.0. Companies adopt it easily, and it includes an explicit patent grant.
- Language: TypeScript everywhere (server, SDK, future dashboard), so one person can maintain the whole stack.
- Monorepo with pnpm workspaces; dependency rules are in `CLAUDE.md`.
